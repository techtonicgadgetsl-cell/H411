⚙️ Health 411 — Area Setup

Fill in the 4 steps, then save the two files it creates (config.js and area-geo.js) in the same folder as index.html.

Step 1 — Your area

These are shown on the pages and pre-filled in the report form (you can leave the last two empty).

Step 2 — Your own database (Firebase)

Every PHI needs their own Firebase project, so your records stay separate from everybody else's.

How to get the Firebase config
  1. Open console.firebase.google.com → Add project (any name, Analytics not needed).
  2. Left menu → Build → Realtime Database → Create database (choose Singapore, start in locked mode).
  3. Project settings (⚙️) → Your apps → Web (</>) → register app → copy the firebaseConfig = {…} block.
  4. Paste it below. It must contain databaseURL (shown only after the Realtime Database is created; if missing, copy it from the Realtime Database page).

Step 2b — Who can log in (patient data security)

Only these e-mail addresses can read or change patient records. Everybody else is refused by the database itself, even if they find your page link.

Do this once in the Firebase console
  1. Build → Authentication → Get started → Sign-in method → Email/Password → Enable.
  2. Authentication → Users → Add user: create an account (e-mail + password) for each address above. Do this before publishing the rules.
  3. Authentication → Settings → User actions: if you see Enable create (sign-up), turn it off, so nobody can register themselves.
  4. Realtime Database → Rules: paste the rules below and press Publish.
  5. When a person leaves, delete the account and remove the e-mail from the rules.
Type the staff e-mail addresses above.

Step 3 — Your area boundary (GeoJSON)

Choose the GeoJSON file of your area (GN divisions as polygons). The coordinate system is detected automatically and converted to GPS (WGS84).

Check the preview: the red outlines should sit on your area. If they are in the wrong place, change the coordinate system above.

Step 4 — GN divisions & PHM areas

Tick the GN divisions that belong to your area and type the PHM area of each (it is filled automatically in the report form). Names can be edited.
